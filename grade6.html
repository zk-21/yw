⭐ 必学 · 特级教师精讲

常见问题：六年级最容易拉开差距的，不是“会不会这道题”，而是做题习惯稳不稳。常见卡点有四个：一是看到题就急着答，没有先判断题型；二是材料题会抄数字，却不会用数字说明问题；三是作文只看见“大概意思”，没抓住题目里限制你写什么的关键词；四是写完就交，不会回头检查有没有漏层次、漏依据。

怎么做：先把诊断做成具体动作。题型判断弱，就每天练 5 题“先说这题考什么”；材料题依据弱，就按“找数据→做比较→写结论”单独练；审题不稳，就固定做“圈题眼、定范围、想中心”三步；答案总写不全，就给孩子一张简短检查单，交卷前按分值自己过一遍。

补齐模块 · 综合运用

六年级综合运用实战：宣传语、提建议、发言和活动方案

六年级很多丢分不在“不会”，而在“说不准、写不全、提得空”。综合运用要把口语交际、应用文和综合性学习压缩成能直接拿分的表达动作。

六年级要练成什么

  • 宣传表达：一句宣传语要有对象、有主题、有感染力。
  • 建议表达：建议必须回到材料，不凭生活经验空喊口号。
  • 方案整理：活动方案要写主题、步骤、分工和成果展示。

答题顺序别乱

先看任务：是拟标题、写宣传语，还是提建议、做发言。

再找材料：凡是给了图表、数据、关键词，都要用进答案。

最后检查：对象对不对，语气得不得体，做法能不能执行。

六年级综合运用任务对照表

任务作答框架达标标准失分提醒
宣传语 / 标语围绕主题，语言简洁，有号召力。一句话点出主题，读起来顺口。只喊“要加油”，看不出具体主题。
提建议对象 + 问题 + 材料依据 + 建议 + 理由。建议和材料能一一对应，不空泛。只写常识，不引用数据或材料。
讨论发言我认为……，依据是……，所以建议……。观点明确，理由具体，语气得体。观点有了，但理由站不住。
活动方案主题、步骤、分工、展示方式四项完整。方案能执行，看得出谁做什么。只有主题，没有过程安排。

补齐模块 · 整本书与现代诗

六年级整本书阅读与现代诗：读出主题、结构和表达效果

六年级这两块要往综合题思路靠：整本书阅读不只说人物和情节，还要概括主题和人物成长；现代诗不只说画面，还要分析意象、手法和情感如何一起服务中心。

整本书阅读冲刺点

  • 主题概括：从人物经历中提炼作品的核心表达。
  • 人物成长：抓住前后变化，写出成长原因。
  • 综合表达：能把书中内容和现实问题联系起来说。

现代诗阅读冲刺点

先看意象：哪些景物最关键，是否反复出现。

再看手法：比喻、象征、反复、拟人如何服务情感。

最后看中心：这些意象和手法共同表达了什么主题。

六年级阅读与诗歌任务对照表

任务做法达标标准专题跳转
主题概括内容概括 + 人物变化 + 主题表达。能把“写了什么”和“想表达什么”分开写清。阅读分类
人物成长分析前后变化 + 关键事件 + 成长认识。答案有层次，不只贴“勇敢、善良”等标签。读书分享
现代诗综合赏析意象 + 手法 + 情感 + 主题。四层基本完整，能从词句回到中心。现代诗专题
比较阅读比较两首诗或两段内容的共同点和不同点。能按角度比较，不混着写。比较思路

孩子直接学

六年级精讲课：综合阅读和非连续性文本

六年级要学会把材料、依据、分析和中心连起来。下面用综合阅读和图表材料做一遍完整示范。

特级教师精讲

常见问题：很多孩子平时单项题做得还行，一到综合卷就乱，根子往往不是不会，而是“换个问法就认不出来”。比如本来该按句段作用答，却套成人物题；本来该根据材料提建议，却开始凭感觉发挥。说白了，就是题型没先看清，步骤没先想明白。

怎么做：每次做题前先停 5 秒，先写一句：“这是什么题？要答几层？”把这一步练熟，比盲目多刷题更有用。六年级往中学过渡，真正要练的是孩子能不能自己先判断、自己选方法、自己检查，而不是永远等别人提醒。

教师版说明

这一段原本强调的是：孩子在单题型里学会的方法，未必能自动带到综合卷里，所以需要把“先辨题型、再选步骤”练成稳定习惯。面向家长时，用“换个问法就乱”“先停 5 秒判断题型”更容易理解，也更方便落到陪学动作上。

课堂材料

材料一：六年级三个班每天阅读 30 分钟以上的人数分别是 18 人、24 人、16 人。材料二：坚持阅读的学生在习作中更容易写出具体事例和真实感受。

问题：根据材料，给六年级学生提一条阅读建议。

专业解析：建议六年级学生每天坚持阅读 30 分钟以上。材料一显示三个班都有学生能做到持续阅读，材料二说明坚持阅读有助于习作写出具体事例和真实感受，因此每天固定阅读时间能提升阅读和写作能力。

老师提醒：这类题先把材料里的关键信息找出来，再看看几则材料共同在说明什么，最后再提建议。建议不是凭自己觉得对，而是要让材料能支持得住。

例题、解析和变式

题目标准答案为什么这样答变式练习
非连续文本建议题建议 + 材料依据 + 理由答案不是空喊口号，而是用材料支撑建议。根据运动数据，给同学提健康建议。
句段作用题内容作用 + 结构作用 + 中心作用六年级作用题要分层，不能只写承上启下。分析文章结尾"我终于明白了"的作用。
作文审题题眼 + 中心 + 重点材料先确定写什么变化，再决定哪里详写。以"这一次，我懂了"为题列提纲。

课堂精讲 2

六年级综合阅读课：句段作用分三层答

特级教师精讲

常见问题：孩子最容易犯的错，是只写“承上启下”“总结全文”这类术语，不把后面的内容补出来。这样看上去像答了，其实还没真正回答“承接了什么、引出了什么、和中心有什么关系”。

怎么做：草稿纸上先分三格来答：内容层写“这句话写了什么”，结构层写“它和前后文什么关系”，中心层写“它帮全文表达了什么”。三格都写完，再连成一句完整答案，作用题就不容易只剩套话了。

课堂短文

我站在讲台前，手里的稿纸微微发抖。台下那么多双眼睛望着我，我差点想转身逃走。可想到这几周一遍遍练习的夜晚，我深吸一口气，终于开口说出了第一句话。

  • 内容层：写"我"演讲前紧张但鼓起勇气。
  • 结构层：承接前面的练习，引出后面正式演讲。
  • 中心层：表现成长来自一次次坚持和尝试。

带练解析

题目：这段话在文中有什么作用？

标准答案：内容上写出"我"上台前紧张却努力鼓起勇气；结构上承接前文的反复练习，引出下文正式演讲；中心上表现了"我"在坚持和尝试中获得成长。

老师判断：如果孩子只写“承上启下”，说明他知道术语，但还不会展开分析。六年级这类题必须把术语后面的内容补出来：承接了什么、引出了什么、和中心有什么关系。

题目、答案和变式

题目标准答案解析变式练习
"稿纸微微发抖"写出了什么？写出"我"演讲前非常紧张。抓动作细节，推断人物心理。分析"他低着头不说话"。
概括人物变化"我"从紧张想逃走，到鼓起勇气开口演讲。变化题要写前后状态。概括一次考试前后的心理变化。

特级教师精讲

常见问题：作文最常见的丢分点，不是“不会写”，而是审题时抓错重点。孩子一看到“长大了”“懂了”这种熟词，就很容易顺手往熟路上写，却漏掉“这一次”这种真正限制内容的词。结果就是写了很多，还是偏题。还有一种情况是结尾只写“我很开心”“我很感动”，有感受，但没有再往前走一步，说清自己到底明白了什么。

怎么做：审题先做三步：先圈限制词，再圈题眼，最后问自己“如果少了这个词，题目意思会不会变”。写结尾时，也别只停在情绪上，往前再走半步，把“我感到……”改成“我明白了……”。这样中心会更稳，作文也更像六年级该有的水平。

教师版说明

原文这里想说明的是：孩子常把注意力放在熟悉词上，忽略真正限制内容的关键词，所以会“看起来没跑题，其实没扣准”。改写后把它落成“圈限制词、圈题眼、反问少哪个词意思会变”，更方便家长直接拿去陪孩子审题。

题目、答案、解析、错因

任务标准答案解析常见错因变式
题目《这一次，我长大了》圈题眼题眼是"这一次"和"长大了"。必须写一次具体经历，还要写出认识上的成长。只写年龄长大，或者写很多次事情。圈《那一刻，我懂了》的题眼。
确定中心通过独自照顾生病的妈妈，写出我懂得了承担责任。中心要有成长或认识提升。只写事情感人，没写自己变化。给"第一次独自回家"定中心。
结尾点题那一刻我明白，长大不是说自己多能干，而是愿意为家人承担一点责任。回扣题目，并写出新的认识。结尾只写"我真开心"。写一个扣"懂了"的结尾。

递进题组

层级题目标准答案解析与错因
基础判断题型："这段话在文中有什么作用？"句段作用题。先判断考点，再决定答题层次。
提升运用分层作答卡完成句段作用题内容上写出了……结构上承上启下……中心上突出了……三层逐一检查，不遗漏任何分析维度。
拔尖自主完成综合题型的策略选择和答案组织先判断题型（概括/作用/人物/中心），再选择对应的答题框架。避免题型混淆——不同题型对应不同的答题层次。

孩子原文：妈妈生病了，我给她倒水，还帮她拿药。我觉得我长大了。

老师判断：这段原稿像在列任务清单：倒水、拿药、盖被子都写了，但“我为什么慌、怎么稳下来、最后明白了什么”还没写出来。六年级作文最重要的就是把动作写成体验，把体验写成认识。

升格片段：看到妈妈靠在沙发上皱着眉，我一开始手忙脚乱，连水杯都差点拿掉。可当她轻声说"没事"时，我忽然觉得自己不能只站在旁边。我倒好温水，按说明找出药，又把被子轻轻盖在她身上。那一刻我明白，长大不是说自己多能干，而是愿意为家人承担一点责任。

常见错法归类

综合题常见失分：题干里的限制词没看全，只抓到熟悉的那一半，结果整题答偏了。

非连续文本常见失分：提建议只凭生活经验，没有回到材料里的数据和信息，所以答案看着顺，却站不住。

作文常见失分：事情写得完整，但结尾停在“我很难忘”“我很感动”，还没真正写出“我明白了什么”。

常见问题：综合题一多，孩子很容易把上一题的答法直接套到下一题。刚做完作用题，下一题人物题也按“承上启下”那套想；刚做完材料题，作文又写成列提纲。不是不会，是换不过来。

怎么做：每做一道新题，先在题边写两个字：题型。再写一句“这题我要答哪几步”。用这个小动作提醒自己换挡；错题本也按题型分开记，复习时更容易分清不同题到底怎么答。

阅读失分诊断

题目：文章结尾有什么作用？

自主学习策略框架

阅读：结论 + 原文依据 + 具体分析 + 情感/中心。重点是答题前先判断“这是什么题”，答完后再看自己有没有漏层次。

非连：提取信息 + 比较异同 + 得出结论。重点是养成“材料里有什么，我就根据什么说”的习惯。

古诗：意象 + 画面 + 手法 + 情感。重点是别只会翻译字面意思，还要能说出画面和感情。

文言：注释 + 连句 + 概括 + 道理。重点是先看注释，再把句子顺通，不要急着凭感觉猜。

作文：审题 + 选材 + 详略 + 细节 + 点题。重点是写每一段时都知道这段和中心有什么关系。

审题与证据

题目一来，先判断考什么

六年级提优的关键不是背更多模板，而是能从题干里判断考点，再回到文本找最有力的依据。

特级教师精讲

常见问题：学生最常见的审题失败表现为"关键词误读"——将"有什么作用"误判为"写了什么内容"（概括题），或将"结合材料说明"按"自由发挥"处理。这种错误源于"题干信息部分提取"——大脑在快速阅读中倾向于提取最熟悉的词汇（如"什么"）而忽略限定性词汇（如"作用""材料"），导致题型定位偏离。此外，学生常将"多次出现的常规用词"归类为无关信息而跳过，而这些词往往是题型判定的最关键线索。

怎么做：实施"关键词高亮法"——在审题训练中要求学生用不同颜色标注不同类型的题干关键词：红色标注题型指示词（概括/作用/为什么/能否删去），蓝色标注范围指示词（第几段/全文/材料一），绿色标注题型限制词（结合原文/至少两点）。这种视觉编码将隐性的审题过程外显化，不仅提高了审题准确性，更重要的是培养了学生对题干语言的分析习惯——这正是自主学习者在面对新题型时的核心能力。

找证据三步法

先定位：看题目要求是全文、第几段、画线句，还是某一则材料。

再圈词：圈最能证明答案的关键词、动作、语言、数据或情节。

后解释：不要整段照抄，要说明这个词句为什么能证明你的结论。

按分值组织答案

2 分题：结论 + 原文依据。

3 分题：结论 + 原文依据 + 简要分析。

4 分题：分点作答 + 依据 + 分析 + 情感/中心。

提醒：分值越高，越不能只写一句话；答案要有层次。

六年级新增重点题型

特级教师精讲

常见问题：非连续性文本最容易错在“凭常识答题”。题目让提建议，孩子一张嘴就是“要多读书”“要多运动”，但没用上材料里的数据和信息。还有些孩子会抄到数字，却不比较、不分析，答案看着有依据，其实还是没说到点上。

怎么做：这类题固定按一个顺序写最稳：先写“根据材料几”，再写具体数据或信息，然后补一句比较或发现，最后再写结论或建议。让孩子形成“先看材料再开口”的习惯，比单纯背模板更重要。

教师版说明

这段保留的理论核心是“证据先于观点”。孩子不是真的不会提建议，而是太容易直接调用生活经验。家长版改写后，把重点放在“材料几 + 数据 + 比较 + 结论”这条明线，更利于训练落地。

什么是非连续性文本

非连续性文本包括图表、表格、清单、统计图、说明书、图文组合等。它不靠普通的讲故事的方式组织信息，而是通过图形、列表、分段等让读者快速找到关键点。

常见题型：根据图表提取信息、比较两三则材料的异同、判断信息正误、根据信息提建议或写结论。

答题三步法

「看题看图表」—— 先看题目问什么，再找数据、对比和结论。

「圈关键」—— 圈题目中"从材料一看""下列说法正确/错误的是""结合材料"等限定词。

「组答案」—— 必须用原文信息作答，不能凭空猜测。

记叙文阅读

记叙文阅读题型与提优要求

特级教师精讲

常见问题：六年级记叙文阅读里很常见的一种情况是：分开练时做得不错，一到综合卷就容易乱。孩子不是完全不会，而是太依赖“刚练过的那一类题”，题目稍微换个壳，就不知道该用哪种答法了。

怎么做：除了平时的分类练习，还要加一点“不给提示”的综合训练。也就是不提前告诉孩子这题属于哪一类，让他自己先判断、自己选方法、自己组织答案。做完后再复盘：你刚才把它当成什么题？这样判断对不对？下次如果再错，应该换哪种答法？这一步特别能帮助孩子把方法真正用活。

教师版说明

原文强调的是：孩子容易把方法和某个熟悉练习场景绑在一起，换卷面就调不出来。家长版改成“换个壳就不会用”“加一点不给提示的综合训练”，既保留了训练方向，也更容易被家长接受。

说明文重要提醒

六年级说明文常结合非连续性文本出现。重点掌握：说明方法判断、语言准确性分析、段落作用。

答题公式：「说明方法 + 说明对象特点 + 表达效果」和「词义 + 删去后变化 + 准确性体现」。

文言文综合训练

会借助注释读懂全文，能回答：词语解释、句子翻译、内容概括、道理启示。

常见实词：之、其、而、于、以、为、乃、则、何、且。

古诗赏析综合训练

六年级古诗赏析要求更高，不再是"写了什么情感"，而是"用了什么手法表现这种情感"。

步骤：抓意象→想画面→辨手法→悟情感

古诗满分判定标准

意象准确：抓住月、柳、雁、梅、雨、舟等关键词，不能脱离诗句乱猜。

画面具体：写清景物、状态、氛围，而不是只翻译诗句。

手法明确：判断借景抒情、托物言志、动静结合、对比、用典等。

情感落准：结合意象和背景，答出思乡、惜别、忧国、赞美、言志等具体情感。

满分模板：诗人通过……等意象，描绘了……的画面，运用……的手法，表达了……的情感。

炼字模板："……"字写出了……的特点，营造了……的氛围，也表现了诗人……的心境。

🚀 拓展 · 低分到满分

六年级拔尖要训练满分答案

满分答案五要素

① 审题准：先判断题型，不答偏、不漏问。

② 结论明：第一句话直接回答问题。

③ 依据实：引用原文关键词、情节、数据或材料信息。

④ 分析透：解释依据如何证明结论。

⑤ 表达清：必要时分点，句子完整，术语准确。

答题自检策略（基础能力）

有没有直接回答？第一句话必须先亮明结论，别绕圈子，这样阅卷老师一眼就能看到你答到了重点。

有没有原文依据？引用原文关键词或情节，避免凭感受答题——这是"证据意识"的自查节点。

有没有解释依据？说明"为什么这个依据能证明结论"，避免只摘抄——这是"推理完整性"的自查节点。

有没有扣住中心？确认答案指向了全文主旨，而非停留在局部——这是"思维层次性"的自查节点。

这四项自检构成一个完整的基础能力循环，是中学阶段独立学习时最核心的答题自评工具。六年级学生应在每次完成练习后使用此检查清单自我评估。

共用阅读材料：《雪地里的背影》

那年冬天，父亲送我去车站。雪下得很大，风吹在脸上像小刀一样。父亲一手提着行李，一手替我挡着风，鞋子踩进雪里，发出咯吱咯吱的声音。到了车站，他先把我安顿到座位上，又转身去买了两个热包子，塞到我手里，只说："路上吃，别饿着。"车开动时，我看见父亲站在雪地里向我挥手，雪花落满他的肩头，他却一直望着车窗的方向。那一刻，我忽然觉得父亲的爱不是挂在嘴边的话，而是藏在一次次沉默的行动里。

答题前先圈证据

人物行动：提行李、挡风、安顿座位、买热包子。

环境描写：雪大、风冷、雪花落满肩头。

中心句：父亲的爱不是挂在嘴边的话，而是藏在一次次沉默的行动里。

共用说明材料

海豚通常用肺呼吸，需要定时浮出水面换气。遇到受伤、幼小或特殊训练的海豚时，它们浮出水面的频率会有所不同。

关键词：通常。

作用：表示一般情况，不排除特殊情况。

共用非连续性材料

材料一：每天运动 1 小时的学生体质良好比例为 72%，每天运动 30 分钟以内的学生体质良好比例为 48%。

材料二：坚持户外运动有助于增强体质，也能缓解长时间用眼带来的疲劳。
