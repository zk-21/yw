题目、答案和评分

题目标准答案评分点常见错因
1. “大约”能不能删去？不能。“大约”表示估计，删去后变成完全确定，与实际可能不符。词义、删后变化共 3 分只写“不能，不准确”。
2. 材料里说明了什么？竹笋生长快，但生长速度会受环境影响。对象、特点、条件共 4 分只写“竹笋长得快”。
3. 爸爸是怎样的人？爸爸是关爱孩子、默默付出的人。品质 2 分，依据 2 分只写“爸爸很好”。
4. 从哪里看出爸爸关爱孩子？把伞往我这边推，自己肩膀湿了；又给我买热包子。两处依据 4 分只答一处或只写感受。
5. 给《那一次，我懂得了坚持》列提纲中心：摔倒后继续练习，懂得坚持。详写：想放弃又重新站起来的一幕。中心、详写、成长共 4 分只写事情经过，没有认识变化。

孩子直接学

五年级精讲课：说明文语言和人物分析

五年级答案要从“会套格式”变成“分析具体”。这里用说明文和人物题各讲一遍。

知识点讲解

  • 说明文准确性：先解释词语意思，再说删去后意思怎样变化，最后点出体现语言准确。
  • 说明方法作用：先判断方法，再说明对象特点，最后说具体、准确或形象的表达效果。
  • 人物分析：不能只写“善良、勇敢”，必须用具体情节支撑。

课堂材料

竹子生长速度很快。在适宜的环境中，有些竹笋一天大约能长高几十厘米。竹子的茎中空而有节，既轻便又坚韧，因此常被用来制作家具、竹篮和乐器。

问题：“大约”能不能删去？为什么？

满分答法：不能删。“大约”表示估计，不是完全确定。删去后就变成有些竹笋一天一定能长高几十厘米，与实际情况不一定相符，体现了说明文语言的准确性。

例题、解析和变式

题目标准答案为什么这样答变式练习
说明方法“几十厘米”用了列数字，具体说明竹笋生长速度快。答案写清了方法、对象和特点。分析“像一把小伞”用了什么说明方法。
词语能否删去词义 + 删去后变化 + 准确性这是说明文高频满分结构。分析“通常、可能、左右”能否删去。
人物题迁移特点 + 具体事例 + 简要分析五年级人物题必须有文本证据。用“冒雨送伞”分析人物品质。

课堂精讲 2

五年级阅读课：人物形象必须用事例支撑

课堂短文

天快黑了，雨越下越大。爸爸把伞往我这边推了推，自己的肩膀却湿了一大片。到了车站，他又把热包子塞到我手里，只说：“趁热吃，别饿着。”

  • 人物：爸爸。
  • 细节：伞往我这边推、肩膀湿、买热包子。
  • 品质：关爱孩子、默默付出。

满分答法

题目：爸爸是个怎样的人？

标准答案：爸爸是一个关爱孩子、默默付出的人。从他把伞往“我”这边推，自己肩膀湿了一大片，还给“我”买热包子可以看出，他把孩子放在心上，自己辛苦却不多说。

错因：只答“爸爸很好”，没有具体事例支撑。

题目、答案和变式

题目标准答案解析变式练习
“塞”字好在哪里？写出爸爸动作快而坚定，表现出他对“我”的关心。赏析动词要联系人物情感。赏析“他轻轻盖好被子”的“轻轻”。
概括这一片段雨天，爸爸送“我”去车站，并细心照顾“我”。概括保留人物、事件和情感。概括“奶奶等我回家”的片段。

课堂精讲 3

五年级作文课：中心决定详略

题目、答案、解析、错因

任务标准答案解析常见错因变式
题目《那一次，我懂得了坚持》确定中心通过学骑车摔倒又继续练习，写出坚持带来成长。中心不是“骑车”，而是“懂得坚持”。只写事情经过，结尾没有认识。给《我战胜了害怕》定中心。
哪一段详写？详写摔倒后想放弃，又重新站起来练习的过程。最能表现中心的地方详写。平均用力，买车、回家、吃饭都写很多。给“第一次演讲”安排详略。
升格结尾原来坚持不是不害怕失败，而是摔倒后还愿意再试一次。结尾写出认识，立意更高。只写“我很开心”。写一句关于“责任”的升格结尾。

递进题组

层级题目标准答案解析与错因
基础“大约”能删吗？不能。“大约”表示估计，删去后变成完全确定，体现说明文语言准确性。准确性题要写词义、删后变化、准确性。

作文批改样例

孩子原文：我学骑车，摔倒了很多次，最后学会了。我很开心。

批改意见：事件完整，但立意不够。重点不是“学会骑车”，而是“坚持带来成长”。需要详写最想放弃的一刻。

升格片段：膝盖擦破后，我扶着车把站在原地，眼泪差点掉下来。爸爸没有催我，只问：“还试一次吗？”我看着那条弯弯的路，重新跨上车。风吹过耳边时，我忽然明白，坚持不是不摔倒，而是摔倒后还愿意再试。

错因分类

说明文错：只写“准确”，不写词义和删后变化。

人物题错：特点词正确，但缺少具体事例。

作文错：材料多但中心散，详略没有服务中心。

知识点递进题组

知识点递进题标准答案/要点解析与错因

春雨过后，竹林里的竹笋长得很快。有些竹笋一天大约能长高几十厘米。研究发现，温度、水分和土壤都会影响竹笋的生长速度。人们常用“雨后春笋”形容新事物大量出现。

A卷：题目、答案和评分

题目标准答案评分点常见错因
1. “大约”能删去吗？为什么？不能。“大约”表示估计，删去后变成完全确定，与实际可能不符，体现说明文语言准确性。词义、删后变化、准确性共 4 分只写“不能，不准确”。
2. 材料 A 主要说明什么？说明竹笋在春雨后生长快，但速度受温度、水分和土壤影响。对象、特点、影响因素共 4 分只写“竹笋长得快”，漏条件。
3. 材料 B 中爸爸是怎样的人？爸爸关爱孩子、默默付出。从他把伞推向“我”、自己肩膀湿了，还给“我”买热包子可以看出。特点、两处依据、分析共 5 分只写“爸爸很好”。
4. “我低头看着热气，忽然说不出话来”表达了什么？表达“我”被父亲无声的关爱打动，也表现出对父亲的感激。情感 + 原因共 3 分只写“我很感动”，没有分析。
5. 给《那一次，我懂得了坚持》列中心和详写段中心：摔倒后继续练习，懂得坚持带来成长。详写：最想放弃又重新站起来的一幕。中心、详写、成长认识共 5 分只写事情经过，没有认识提升。

B卷：同类变式迁移

变式题标准答案/要点错因编码通过标准
1. “几乎全部”能删去“几乎”吗？不能。“几乎”表示接近全部但不是完全全部，删去后说法绝对，体现说明文语言准确。R3词义、删后变化、准确性完整。
2. 概括材料：海鸟迁徙受季节、食物和气候影响材料主要说明海鸟迁徙会受到季节、食物和气候等因素影响。R1说明对象和影响因素都不漏。
3. 爷爷是怎样的人？从两处细节说明爷爷耐心、关爱孩子。从他一遍遍教“我”修车，又把工具轻轻递给“我”可以看出。R2特点 + 两处依据 + 分析。
4. 给《那一次，我学会了负责》列中心和详写段中心：主动完成班级任务，懂得负责。详写：想推脱到主动承担的变化。W2中心有认识，详写最能表现变化的一幕。

五年级必须形成的 5 个能力

  • 主题分析：能概括文章中心思想，而不是只说“很感人”。训练时先概括事件，再追问“作者想表达什么”。
  • 人物分析：能结合语言、动作、心理、事例分析人物形象。答题固定写“特点 + 原文依据 + 具体分析”。
  • 结构意识：能判断开头、过渡、照应、结尾的作用。先看位置，再分别想内容作用和结构作用。
  • 说明文能力：能判断说明方法，分析语言准确性。每次都说清“说明对象的什么特点”。
  • 写作能力：能围绕中心选材，安排详略，结尾点题。写前先写一句中心，再圈出最该详写的一幕。

提优总口诀

中心：主要内容 + 作者情感或道理。

人物：特点 + 原文依据 + 具体分析。

作用：位置 + 内容 + 情感或结构作用。

说明：方法 + 说明对象特点 + 表达效果。

作文：中心明确，详略得当，首尾照应。

词句含义表层意思 + 深层含义 + 中心表面上指……，实际上写出了……，表现了……。只解释字面意思。

记叙文训练：父亲的背影

那年冬天，父亲送我去车站。雪下得很大，地上积了厚厚一层。父亲提着我的行李箱走在前面，我跟在他身后。他的背影在雪地里显得有些单薄，但步伐却很坚定。到了车站，父亲帮我安顿好座位，又给我买了热腾腾的包子。车要开了，父亲站在站台上向我挥手，雪花落在他的头发上，他却浑然不觉。看着父亲渐渐远去的背影，我的眼眶湿润了。

基础题：文章写了一件什么事？

提优题：文中的父亲是一个怎样的人？请结合原文分析。

拔高题：文章多次写“雪”有什么作用？

满分答法：写雪交代了寒冷的环境，烘托出父亲送“我”时的辛苦，也更能突出父爱的深沉。

人物形象答题示范

低分答案：父亲很好，很爱我。

满分答案：父亲是一个关爱孩子、默默付出的人。从他冒雪送“我”去车站、帮“我”安顿座位、买热包子可以看出，他把孩子放在心上，自己辛苦却不说出来。

方法点：人物特点不能只贴标签，必须用原文事例支撑。

说明文阅读

说明文重在准确、清楚、有条理

五年级说明文考点怎么用

考点判断方法作用答法
举例子有“比如、例如、如”等词通过具体例子说明事物特点，使说明更具体
列数字出现具体数字用准确数字说明特点，使说明更准确
作比较把两个事物进行对比突出说明对象的特点
打比方用比喻来说明使抽象内容更形象易懂
分类别按类型分开说明使说明更有条理
语言准确性“大约、通常、可能、左右”等词体现说明文语言准确、严谨

说明文训练：松鼠

松鼠是一种漂亮的小动物，乖巧、驯良，很讨人喜欢。它们面容清秀，眼睛闪闪发光，身体矫健，四肢轻快。松鼠喜欢在树上活动，窝通常搭在树枝分叉的地方，又干净又暖和。松鼠主要吃松果、榛子等坚果，也会把食物藏在树洞里，留着冬天吃。松鼠一胎通常生三四个幼崽。

基础题：这段文字主要介绍了松鼠哪些方面？

提优题：“通常”能不能删去？为什么？

拔高题：这段说明语言有什么特点？

满分答法：“通常”不能删，表示一般情况，不排除特殊情况，体现了说明文语言的准确性。

说明方法答题示范

题目：“松鼠一胎通常生三四个幼崽”用了什么说明方法？有什么作用？

满分答案：用了列数字的说明方法，用“三四个”准确说明松鼠一胎幼崽的数量，使说明更具体、更准确。

古诗词赏析

五年级古诗要能分析意象、情感和表达手法

五年级古诗词情感怎么用

情感类型常见意象分析方向答题表达
思乡怀人明月、秋风、故园、家书借景抒情借……表达诗人对家乡或亲人的思念。
送别惜别柳、酒、孤帆、长亭、远影景中含情通过送别场景表达依依不舍和祝福。
热爱自然春风、花鸟、山水、田园动静结合描写自然景色，表达喜爱和赞美。
托物言志梅、竹、松、石灰、荷花借物写人借……表现诗人高洁、坚强或不屈的品质。
忧国忧民战争、百姓、边塞、寒夜联系背景表达诗人对国家命运或百姓疾苦的关心。
人生哲理登高、流水、山路、明月由景悟理通过景物描写表达某种人生道理。

古诗赏析四步法

第一步：抓意象。看诗中写了哪些景物或事物。

第二步：想画面。把景物连成一幅画面。

第三步：辨情感。判断诗人是思念、赞美、惜别，还是表达志向。

第四步：说手法。常见有借景抒情、托物言志、动静结合、对比。

古诗满分判定标准

画面要具体：写出景物、状态和整体氛围。

手法要点明：借景抒情、托物言志、动静结合、对比等要判断准确。

情感要落准：结合意象和语境，不只写“喜欢/伤心”。

满分模板：诗人通过描写……的画面，运用……的手法，借……表达了……的感情。

炼字模板：“……”字写出了……的特点，使画面更加……，也表现了诗人……的心境。

低分答案到满分答案

题目低分答案满分答案
表达了什么情感？表达了思乡。诗人借明月这一意象，写自己望月时想到远方家乡，表达了浓浓的思乡之情。
“绿”字好在哪里？写出了绿色。“绿”字写出了春风吹过后江南大地草木变绿的景象，使画面鲜明、有生机。
托物言志是什么意思？写东西。诗人表面写某种事物，实际借它表现自己的志向、品格或精神追求。

诗人、词人表达情感的高级路径

表达路径核心理解常见内容满分答题表达
借景抒情通过景物写心情月、风、雨、雪、落日、江水诗人/词人借……的景象，含蓄地表达了……的情感。
情景交融景物和情感融合在一起寒雨、孤舟、残阳、秋风景中含情，……的景象烘托出诗人/词人……的心境。
托物言志借事物表现人格或志向梅、兰、竹、菊、松、石灰表面写……，实际表现诗人……的品格或追求。
用典抒情借历史人物或故事表达情感古人、典故、历史事件借……的典故，表达诗人/词人……的志向或感慨。
对比衬托用差异突出情感今昔对比、动静对比、乐景写哀通过……和……的对比，突出诗人/词人……的情感。
炼字传情一个关键字承载画面和情绪绿、破、惊、满、愁、孤“……”字写出了……的特点，也表现了诗人/词人……的心情。

诗与词的情感表达区别

诗：常借景、借物、叙事表达情感，语言凝练，画面感强。

词：更常写细腻心绪，如离愁、思念、感伤、豪情，节奏和语气更委婉。

答题提醒：遇到词，不只看写了什么景，还要看词人内心的变化。

完整答题模板

第一句：这首诗/词描写了……的画面。

第二句：诗人/词人运用了……的手法。

第三句：借……表达了……的情感。

示例：诗人借明月这一意象，描写月夜思乡的画面，表达了远离家乡时对亲人的思念。

低分到满分

五年级提优要训练答案深度

共用阅读材料：《父亲的背影》

那年冬天，父亲送我去车站。雪下得很大，父亲提着我的行李走在前面，到了车站又帮我安顿座位，给我买了热腾腾的包子。车开了，父亲站在站台上挥手，雪花落在他的头发上，他却浑然不觉。

共用说明材料

句子：松鼠一胎通常生三四个幼崽。

词语：“通常”表示一般情况，不排除特殊情况。

证据：送站、安顿座位、买热包子、雪花落在头发上。

题目低分答案满分答案方法点
概括中心思想文章很感人。文章写了父亲冒雪送“我”去车站的事，表达了父亲对孩子深沉的爱。内容 + 情感
人物形象父亲很好。父亲关爱孩子、默默付出，从他冒雪送“我”、买热包子可以看出。特点 + 依据
环境描写作用写了下雪。写雪交代寒冷环境，烘托父亲送行的辛苦，突出父爱。环境 + 人物 + 中心
说明文语言不能删，不准确。“通常”表示一般情况，删去后变成绝对说法，与事实不符，体现说明文语言准确性。词义 + 删后变化 + 准确性

特级教师拔尖提优

五年级从“会做题”提升到“会分析、会表达”

五年级拔尖要训练答案深度和作文立意，为六年级综合阅读、作文升格和小升初表达打基础。

1. 阅读要答出层次

中心思想、人物形象、环境描写作用不能只答一句，要形成“内容 + 手法 + 作用”的完整表达。

拔尖训练：每道分析题至少写两层意思，并补充文本依据。

2. 说明文要抓准确性

五年级常考说明方法和说明语言，尤其是“能否删去、为什么”。

拔尖训练：按“词义 + 删去后变化 + 体现准确性”组织答案。

3. 作文要有中心和详略

满分作文不是写得长，而是中心明确、材料集中、重点片段细致。

拔尖训练：同一题目列两个立意，选更具体、更有变化的一个写。

拔尖题型示范

五年级普通答案怎么升格

共用材料 A：送站

雪大风冷，父亲冒雪送“我”去车站，帮“我”安顿座位，又买来热包子。车开后，“我”看着父亲站在雪地里的背影，心里久久不能平静。

共用材料 B：说明文与作文情境

说明句：有些竹笋一天大约能长高几十厘米。

作文情境：“我”学骑车时害怕摔倒，后来一次次尝试，终于明白遇到困难不能轻易放弃。

题目普通答案拔尖答案得分点
文章表达了怎样的中心思想？文章很感人。文章通过写父亲冒雪送“我”去车站的事，表现了父亲对子女深沉而含蓄的爱。内容 + 情感
环境描写有什么作用？写天气冷。这里写雪大、风冷，交代了恶劣环境，衬托出父亲送行的辛苦，也更突出父爱的深沉。环境 + 人物 + 中心
“大约”一词能删去吗？不能，删去不准确。不能。“大约”表示估计，不是准确数字，删去后变成肯定说法，与事实可能不符，体现说明文语言的准确性。词义 + 删后变化 + 准确性
作文怎样写出成长？写我学会了骑车。可以写“我”从害怕摔倒到敢于尝试，最后明白遇到困难不能轻易放弃，突出心理变化和成长收获。变化 + 过程 + 感悟
